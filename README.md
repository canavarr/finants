# Finance Accounting Exam App

A web-based practice exam application for Finance Accounting students. 

## Features
- **20 Questions per Session**: Randomly selected from 14 chapters.
- **Timed Exam**: 90-minute timer with visual warnings.
- **Instant Feedback**: Detailed results screen with correct/incorrect validation.
- **Various Question Types**: Dropdown matching, calculations, and multiple choice.
- **Persistent History**: Saves your results locally so you can track progress.
- **Reset Functionality**: Clear your history to start fresh.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Clean "LMS-style" academic theme.
- **JavaScript (Vanilla)**: Core logic, randomizer, and state management.

## How to Run Locally
1. Clone the repository or download the files.
2. Open `index.html` in any modern web browser (Chrome, Safari, Edge).
3. No server or installation required!

## Deployment
This project is static and can be hosted freely on **GitHub Pages**, **Netlify**, or **Vercel**.
